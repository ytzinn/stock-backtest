## 1. 왜 추정량을 바꾸는가

### 1-1. 포트폴리오 CAGR의 정보 압축

`[검증된 사실]` 현행 판정 경로는 각 구간에서 수백 종목의 유니버스를 **13종목 동일가중
수익률 1개**로 압축하고, 그 숫자들로 CAGR을 만든다. 유효 관측 수 = 구간 수.

### 1-2. `[선행 산출 A-1]` CAGR 추정량의 MDE — **산식 정정**

> ### ⚠️ `[정정 v0.2]` v0.1 §1-2의 연율화 승수가 틀렸다
>
> v0.1은 `SE(g) ≈ s_log/√T × √2` 로 적었다. **√2가 아니라 2다.**
>
> ```
> g = Σx_t / years,   years = T/2   (반기 2회/년)
> g = 2·x̄  →  Var(g) = 4·Var(x̄) = 4s²/T  →  SE(g) = 2s/√T
> ```
> √2는 *합의 표준편차* 승수라 다른 양이다. 틀린 식은 **SE를 √2배 과소추정**한다.
>
> `[Claude 의견]` 이 오류의 발원지는 설계서 본문이고, 외부 리뷰는 그 식을 충실히
> 적용했을 뿐이다. **CLOSEOUT §8 교훈 5의 재현이다** — 설계서에 적힌 근사식이
> 검증 없이 실측 스크립트로 복사됐다. 보고서에 들어가는 수치만이 아니라
> **설계서에 들어가는 산식도 `[검증된 사실]` 라벨 대상**이다.

**정정 후 추정값** `[확실하지 않은 사실 — A-1에서 재산출 필수]`
리뷰 실측(`SE=6.02%p`)에서 역산한 `s_log ≈ 0.1806` 기준:

| | 리뷰(구 산식) | **정정** |
|---|---|---|
| SE(연율 로그) | 6.02%p | **≈ 8.51%p** |
| MDE (양측 α=.05, 검정력 .8) | 16.85%p | **≈ 23.8%p** (CAGR 환산 ≈ 26.9%p) |

**§0-1(a) 전제: 통과.** 방향은 바뀌지 않고 강화된다 — 1~2%p는 이 추정량의 해상도 밖이다.

**A-1 구현 요구 (강제)**:
1. **SPEC에서 산식을 베끼지 마라.** 유도부터 오라클 테스트로 고정한다.
   선례: `tests/oracle/test_calendar_sens_oracle.py::test_g_matches_compute_nav_cagr`
   (`CAGR = exp(g) − 1` 이 `compute_nav_cagr` 와 정확히 대응함을 고정).
2. 꼬리 규약을 검정에 맞춘다 — **A-1·A-2 모두 단측**(§4-3 P-1a와 일관).
3. **각주 필수**: 이것은 1표본 근사이고 G1은 추첨 p95 비교다. **결론이 같아도 다른 계산이다.**
4. 재료는 섀도우 세대 `{tag}_periods.csv` 뿐 — 결과 열람과 무관하다.

### 1-3. 횡단면 추정량이 무엇을 늘리는가 — **정확히 말할 것**

| | 늘어나는가 | 설명 |
|---|---|---|
| FM **t의 자유도** | **아니오** | df = T−1. 반기 패널에서 그대로다 |
| **각 구간 추정치의 정밀도** | **예** | λ_t 가 13종목 평균이 아니라 N_t(수백) 종목 회귀에서 나온다 |
| 결과적 t 통계량 | **예** | t = mean(λ)/sd(λ)×√T 에서 sd(λ)가 줄어든다 |
| **월간 확장 시 T** | 예 (조건부) | §4-4 |

> **핵심**: 이득은 "표본이 수천으로 늘어난다"가 **아니다.** 매 구간의 신호-수익 관계를
> **13종목이 아니라 유니버스 전체**로 재기 때문에 **구간별 추정치의 잡음이 주는 것**이다.
> 이 문장을 보고서에 그대로 쓴다.

## 3. 패널 구성 — 데이터 계약

### 3-1. 관측 단위

`(ticker, rebalance_date)` 1행. 구간 t의 해당 계층에 속한 **모든** 종목
(포트폴리오 편입 여부와 무관 — CAGR 추정량과의 결정적 차이).

### 3-2. `[v0.2 보강]` 종속변수 — 전방수익률

**엔진 정의를 재사용한다. 재구현 금지.**

```python
# engine.py / export_portfolios.py 규약 그대로
price_start = get_close_price(conn, ticker, rebal_date)
if price_start is None or price_start <= 0:        # ← v0.1 누락 분기
    skip                                            # engine._period_stock_data 와 동일
if is_delisted_at(conn, ticker, next_date):
    exit_ = _last_known_price(conn, ticker, next_date) * DELISTING_HAIRCUT   # = 0.70
else:
    exit_ = get_close_price(conn, ticker, next_date)
fwd_ret = exit_ / price_start - 1
```

`[검증된 사실]` `DELISTING_HAIRCUT = 0.70` (`engine.py:38`).

> **사전등록 D-1 — 상폐 종목은 패널에서 제외하지 않는다.**
> 제외하면 생존편향이 IC에 직접 들어온다. 저PBR 종목의 상폐율이 높다면 제외 패널의 IC는
> **위쪽으로 편향**된다. `[Claude 의견]` 새 패널 코드의 `dropna()` 로 조용히 사라지기 가장
> 쉬운 항목이며, §5 L-1a가 이를 잡는다.

### 3-3. 독립변수 — 신호

```
inv_pbr_total = 자본총계 / 시가총액        # 총액 기준 (BASIS-RIM-001)
```

주당 지표 금지 — 수정주가는 현재 기준 리베이스, PIT 주식수는 당시 기준이라
분할·무상증자 종목에서 배수로 틀어진다.

| 경우 | 처리 | 근거 |
|---|---|---|
| 자본총계 결측 | 패널 제외 + 구간별 제외율 보고 | 랭킹 불가 |
| **자본총계 ≤ 0 / PBR ≤ 0** | **엔진과 동일하게 제외** `[v0.2 확정]` | `ablation.py:582` 실측. v0.1의 "음수 BM이 최상위로 튄다"는 우려는 **불필요했다** |
| 판정불가 구간 (2016-08-18) | 제외 — §3-6 T 규칙에 포함 | CLOSEOUT §4 |

### 3-4. 표준화

```
1) 구간 t 내 inv_pbr → rank → [0,1] uniform → 역정규변환 (z)
2) fwd_ret: primary(rank IC)는 rank / FM 회귀는 1/99 pct winsorize
```

`[Claude 의견]` 한국 소형주 반기 수익률은 꼬리가 두꺼워 원자료 Pearson 상관이 **단일 종목
1건**에 좌우될 수 있다. trimming 대신 winsorize를 쓰는 이유는 trimming이 관측을 버려
IC를 낙관 쪽으로 밀 수 있어서다.

>   "공식 지표는 완결 구간만")
> - **판정가능**: `{R1,R2,R5,R6}` 전부 판정가능 비율 > 0 (CLOSEOUT §4 산출물 기준)

| T | 구성 | 지위 |
|---|---|---|
| **19** | 완결 20구간 − 2016-08-18 | **primary** |
| 18 | 위에서 2016-04-05 추가 제외 | **G1 정합용 병기** |
| 20 | 전 완결 구간 | 미사용 |

`[Claude 의견]` G1의 n=18은 **복리 연쇄가 연속 집합을 요구**해서 정상 구간인 2016-04-05를
함께 버린 것이다. **IC에는 복리가 없어 그 제약이 없다** — 불연속 구간 집합이 유효하다.
그래서 primary는 19다. 18을 병기하는 것은 G1과 같은 구간 집합에서의 비교를 남기기 위함이다.

**열린 구간은 제외한다.** IC에는 유효 관측이지만, 완결 구간 규칙을 SPEC_15에서만
예외 처리하면 다른 산출물과 비교 불가능해진다.

## 4. 추정량

### 4-1. Rank IC — primary

```
IC_t = Spearman( inv_pbr_i,t , fwd_ret_i,t )        i ∈ L3ᴿ(t)
보고: mean(IC), sd(IC), ICIR = mean/sd, t = ICIR×√T, 구간별 IC 시계열
```

### 4-2. Fama-MacBeth — 병기 primary

```
1단계:  fwd_ret_i,t = a_t + λ_t·z(inv_pbr)_i,t + γ_t·controls_i,t + e_i,t
2단계:  λ̄ = mean(λ_t),  t = λ̄ / (sd(λ_t)/√T),  df = T−1 = 18
```

`[검증된 사실]` FM은 구간 내 잔차 상관(시장·업종 공통 충격)을 **구성상** 흡수한다.
패널 OLS는 SE를 심하게 과소추정한다.

### 4-3. 추론

| 방법 | 지위 | 사유 |
|---|---|---|
| **permutation 귀무분포** (구간 내 재배열, B=1,000, master seed 고정) | **primary** | SPEC_10 §3-1 · SPEC_12 §6-3 관례. T=19에서 정규근사보다 정직하다 |
| FM 표준 t (df=18) | 병기 | 관례적 보고 |
| Newey-West | **반기에서 미적용** | 6개월 forward / 6개월 rebal = 중첩 0. 중첩 없는데 쓰면 lag가 임의값이 된다. §4-4에서만 |

> **사전등록 P-1a**: **단측, α=0.05.** 가치 프리미엄은 방향 가설이 있다.
> 반대 부호로 유의하면 PASS가 아니라 **"신호가 역방향"** 이라는 별도 결론이며,
> **부호를 뒤집어 재검정하지 않는다.**

### 4-4. 월간 재표본 확장 — 2차, 판정 비사용

```
횡단면: 매월 말 (T ≈ 120)   /   신호 분모(시총)는 매월 갱신, 분자(재무)는 반기 갱신
종속:   1개월 전방수익률 (중첩 0)  +  6개월 중첩본은 NW(lag 5) 병기
```

`[Claude 의견]` T를 실제로 늘리는 유일한 경로지만 신호 자기상관이 커서 유효 독립 관측은
120보다 훨씬 작다. **반기와 어긋나면 반기 primary를 따른다** — 반기가 실제 전략의 캘린더다.

> **사전등록 P-1b**: 반기 primary가 FAIL인데 월간이 PASS인 경우를 PASS로 보고하지 않는다.

### 4-5. 가중

동일가중 primary(실제 포트폴리오가 동일가중). √시총 가중은 **강건성 축으로만**.

## 5. 양성·음성 대조 — 본 측정보다 **먼저** 돌린다

CLOSEOUT §8 교훈 1의 직접 적용.

| id | 종류 | 구성 | 통과 조건 |
|---|---|---|---|
| **L-1a** | **배관 — 멤버십** | 패널에서 채택 규칙대로 상위 13종목 → 섀도우 `{tag}_n13_holdings.json` 과 대조 | **편입 종목 집합 완전 일치. 허용오차 없음** |
| **L-1b** | **배관 — 수치** | 같은 tape의 구간 수익률 대조 | `ret` 반올림 반폭 **`5e-7`** (tape은 `round(...,6)`) |
| P-1 | 양성 (강) | 신호 자리에 `fwd_ret` 주입 | rank IC ≈ 1.0 |
| **P-2** | **양성 (약) — 감도** | 설계 IC ≈ 0.03 / 0.05 합성 신호 | 수준별 검출 성공률 → **§6 A-2의 실측 근거** |
| N-1 | 음성 | 구간 **내** permutation, B=1,000 | IC 평균 ≈ 0, 귀무분포 생성 |
| **N-2a** | **N-2의 자기검증 (선행)** | `load_pit_series_ttm(..., fiscal_year=미래)` 가 **실제로 미래 행을 반환하는지** 실측 | 미래 경로가 PIT 경로와 **다른 값**을 내야 한다 |
| N-2b | lookahead 탐지 | 미래 재무 1/PBR의 IC vs PIT 1/PBR의 IC | `IC(future) > IC(PIT)` 여야 정상. **역전·동일이면 PIT가 깨진 것** |

### 5-1. `[v0.2 신설]` L-1을 둘로 나눈 이유

SPEC_13 EQ-1/EQ-2 선례다. 하나로 묶고 허용오차를 주면 **멤버십 오류가 반올림 뒤에 숨는다.**
tape의 `ret` 은 `round(...,6)`, `entry`/`exit` 는 `round(...,0)` 이라 비트 일치를 요구하면
반올림에서 걸린다 — `BASELINES.json` 이 08-24에 정확히 그 문제로 양성 대조를 한 번 떨어뜨렸다.

### 5-2. `[v0.2 신설]` N-2a가 없으면 N-2b는 무력하다

`[확실하지 않은 사실]` `load_pit_series_ttm` 에 미래 `fiscal_year` 를 넣어도 내부에서
`available_from <= rebal_date` 가 여전히 걸려 **조용히 PIT 값을 돌려줄 수 있다.**
그러면 N-2b는 항상 "통과"하는 검사가 된다 — 이 저장소가 일곱 번 잡은
**"없는 것은 오류를 내지 않는다"** 유형이다. **N-2b 실행 전에 N-2a로 증명한다.**

### 5-3. 방법론

**워크트리 대조를 쓴다.** monkeypatch는 이 저장소에서 두 번 실패했다(CLOSEOUT §7) —
둘 다 "패치 지점보다 상류에 방어선이 하나 더 있었다". 하네스 충실성은
음성 대조(무패치 == 패치+원본소스)로 먼저 확인한다.

## 6. `[선행 산출 A-2]` 검출력 — 결과 열람 전 확정

**IC 평균을 보지 않고 산출한다.** 재료는 N-1 permutation 분포의 sd 와 P-2 실측이다.

```
MDE(IC) = t_crit(df=T−1, **단측** 0.05) × sd_null(IC) / √T        ... 정규근사
          + P-2 의 설계 IC 0.03/0.05 검출 성공률로 교차 확인
```

> **A-2는 S-3(대조군) 이후에만 실행 가능하다.** `[v0.2 정정]` v0.1 §10의 세션 분할이
> A-2를 S-3보다 앞에 뒀는데, **A-2의 재료를 만드는 것이 S-3**이라 성립하지 않았다.
> A-1은 `periods.csv` 만 있으면 되므로 맨 앞에 둔다.

> **기록 의무**: MDE(IC)를 **본 측정 산출 전에 커밋한다.** FAIL이 났을 때 "효과 없음"과
> "검출력 없음"을 구분할 유일한 수단이다. MDE가 문헌 전형값(가치 신호 IC 0.02~0.05)보다
> 크면, **그 사실 자체가 이 SPEC의 결론**이 될 수 있다.

## 9. 한계 — 실행 전 명시

### 9-1. T는 19다
FM t의 자유도는 18. 이 SPEC은 **잡음을 줄이는 것**이지 **표본을 늘리는 것이 아니다**(§1-3).

### 9-2. 섹터 통제 불가
`SECTOR-DATA` 미해결. 저PBR이 특정 업종에 몰려 있으면 IC는 **업종 베팅의 산물**일 수 있고
이 설계는 분리하지 못한다. `[Claude 의견]` G5 낙폭 원인 규명에서도 같은 병목이었다.

### 9-3. IC → IR: breadth 산술 **(실행 전 필독)**

`IR ≈ IC × √breadth` (Grinold):

```
n=13, 반기 2회  →  breadth = 26  →  √26 = 5.1
IC = 0.03  →  IR ≈ 0.15        IC = 0.05  →  IR ≈ 0.25
```

`[Claude 의견]` **문헌 전형 IC가 사실이어도 이 구조의 실현 IR은 0.15~0.25다.** 그리고
IR 0.15를 T=19 표본에서 CAGR로 검출하는 것은 §1-2 MDE(≈24%p)에 비추어 불가능하다.
**즉 "IC PASS + G1 FAIL"은 예상 가능한 정합적 결과다.** 실행 전에 적어두지 않으면
사후에 지어낸 변명처럼 읽힌다.

breadth가 진짜 병목일 가능성도 시사하지만 그것은 후속 SPEC의 가설이며,
**여기서 종목 수를 바꾸지 않는다.**

### 9-4. `[v0.2 보강]` 유동성 — 이미 잘린 분포다

`[검증된 사실]` HardFilter가 L1에서 **일평균 거래대금 1억원 컷**을 건다(`hard_filter.py:32`).
따라서 L3ᴿ의 `log_turnover` 통제와 유동성 3분위 진단은 **이미 절단된 분포 안**에서의
비교다. "초소형주에서 IC가 나오는가"를 이 설계로는 온전히 답할 수 없다 —
컷 아래 구간이 패널에 없기 때문이다. 3분위 IC는 **판정 비사용 진단**으로만 보고한다.

## 부록 — 용어

**IC**: 한 시점에서 신호 순위와 이후 실현수익 순위의 상관. 포트폴리오를 만들지 않고
신호 자체의 예측력을 재는 지표.

**ICIR**: IC 평균 ÷ IC 표준편차. 신호가 얼마나 **꾸준히** 맞는지.

**Fama-MacBeth**: 시점별 횡단면 회귀 계수를 먼저 구하고(1단계), 그 계수 시계열의 평균을
검정하는(2단계) 2단 추정. 구간 내 잔차 상관을 구성상 흡수한다.

**Breadth**: 독립적 베팅의 수. `IR ≈ IC × √breadth`. 신호가 좋아도 베팅 수가 적으면
실현 성과는 잡음에 묻힌다.

**MDE**: 주어진 표본·검정력에서 검출 가능한 최소 효과. **FAIL의 의미를 해석하려면 필수** —
MDE를 모르면 "효과 없음"과 "검출력 없음"이 구분되지 않는다.

**L3ᴿ**: L3 중 랭킹 산출이 실제로 가능한 부분집합(`equity > 0` 且 `pbr > 0`).
E1의 모집단.

## 0. 이 문서가 **아닌** 것 — 먼저 읽어라

`[Claude 의견]` **이 설계서의 최대 위험은 통계가 아니라 순서다.**

CAGR 추정량으로 판정했더니 FAIL이 나왔고, 그 직후에 추정량을 바꾸는 문서를 쓰고 있다.
외형만 보면 이 프로젝트가 `FactorScreener` 폐기(2026-07-05)에서 스스로 정의한
**결과를 보고 기준을 고르는 행위**와 구별되지 않는다. 구별하려면 세 가지가 필요하다.

**(a) 정당화가 사전적(a priori)이어야 한다.**
"18구간 포트폴리오 CAGR로 1~2%p를 구분할 수 없다"는 명제는 **G1 결과를 몰라도 참이다.**
표본 크기와 구간 수익률 분산만으로 계산되며, §1에서 실제로 결과 미열람 상태에서 산출한다.
만약 §1의 검출력 계산이 "CAGR 추정량으로도 1~2%p를 충분히 구분할 수 있다"고 나오면
**이 SPEC은 착수하지 않는다.** 그것이 이 절의 검증 가능한 형태다.

**(b) SPEC_15는 G1을 뒤집지 않는다.**
G1은 "**이 포트폴리오의 실현 CAGR**이 같은 풀 무작위 추첨 p95를 넘는가"를 물었고,
답은 FAIL이다. SPEC_15는 "**랭킹 신호에 횡단면 예측력이 있는가**"를 묻는다. **다른 질문이다.**

> **사전등록 규칙 P-0**: SPEC_15의 어떤 결과도 G1·G2·G5 판정을 수정·무효화·대체하지
> 않는다. `docs/CANONICAL.md` 의 게이트 표는 SPEC_15 실행 후에도 그대로다.
> IC PASS는 "채택 가능"이 아니라 "**신호가 죽지 않았다**"만 의미한다.

SPEC_12 §5-8이 "실험 PASS ≠ 프로덕션 채택"을 분리한 것과 같은 장치다. 그때보다 이번이 더
위험하다 — 그때는 상위 게이트가 살아 있었고, 지금은 **상위 게이트가 방금 FAIL했다.**

**(c) IC가 유의해도 포트폴리오가 안 될 수 있다 — 이건 모순이 아니다.**
§9-3의 breadth 산술을 실행 전에 읽어라. 이 프로젝트의 구조에서는 **IC가 통계적으로 유의해도
실현 IR이 0.2 미만**일 수 있고, 그것이 G1 FAIL과 완전히 정합한다. 이 가능성을 미리
이해하지 않으면 "IC PASS인데 CAGR FAIL"을 배관 오류로 오독하게 된다.

## 1. 왜 추정량을 바꾸는가 — 결과 열람 전에 계산할 것

### 1-1. 포트폴리오 CAGR의 정보 압축

`[검증된 사실]` 현행 판정 경로는 각 리밸런싱 구간에서 수백 종목의 유니버스를
**13(또는 20)종목 동일가중 수익률 1개**로 압축하고, 그 18개 숫자로 CAGR을 만든다.
G1은 그 CAGR 하나를 무작위 추첨 분포와 비교한다.

즉 **전체 표본의 유효 관측 수 = 18** 이다. 종목이 몇 개든, 유니버스가 몇 백 종목이든.

### 1-2. `[선행 산출 A-1]` CAGR 추정량의 최소검출효과(MDE)

**결과 미열람 상태에서 산출 가능하다.** 필요한 것은 구간 net 수익률의 표준편차뿐이고,
그것은 이미 발행된 `{tag}_periods.csv` 에 있다(신규 판정이 아니라 기존 산출물 재사용).

```
구간 수익률 sd = s          (반기)
연율 로그수익률 g 의 SE ≈ s_log / sqrt(T) × sqrt(2)      # 반기 2회/년
양측 α=0.05, 검정력 0.8 기준 MDE ≈ 2.8 × SE(g)
```

`[Claude 의견]` 이 프로젝트 소형주 반기 수익률의 sd가 20%대라면 T=18에서 MDE는
**연 10%p 이상**이 된다. 즉 "1~2%p 차이"는 애초에 이 추정량의 해상도 밖이다.
**실제 수치는 A-1에서 산출한다 — 위 문장은 예상이고, 산출값이 다르면 §0(a)에 따라
이 SPEC의 전제가 무너진다.**

### 1-3. 횡단면 추정량이 무엇을 늘리는가 — **정확히 말할 것**

`[Claude 의견]` 여기서 흔한 과장이 나온다. 정직하게 쓴다.

| | 늘어나는가 | 설명 |
|---|---|---|
| Fama-MacBeth **t의 자유도** | **아니오** | df = T−1 = 17. 반기 패널에서는 그대로다 |
| **각 구간 추정치의 정밀도** | **예** | λ_t 가 13종목 평균이 아니라 N_t(수백) 종목 회귀에서 나온다. Var(λ_t) 가 크게 준다 |
| **결과적 t 통계량** | **예** | t = mean(λ)/sd(λ)×√T 에서 sd(λ)가 줄어든다 |
| **월간 확장 시 T** | **예 (조건부)** | §4-4. 1/PBR의 분모(주가)는 매일 갱신되므로 월간 횡단면이 새 정보를 갖는다. 단 재무 분자는 반기 갱신이라 신호 자기상관이 크다 |

> **핵심**: 전환의 이득은 "표본이 18에서 수천으로 늘어난다"가 **아니다.**
> 매 구간의 신호-수익 관계를 **13종목이 아니라 유니버스 전체**로 재기 때문에
> **구간별 추정치의 잡음이 줄어드는 것**이다. 이 문장을 보고서에 그대로 쓴다.

## 3. 패널 구성 — 데이터 계약

### 3-1. 관측 단위

`(ticker, rebalance_date)` 1행. 구간 t에 계층 L에 속한 **모든** 종목이 들어간다
(포트폴리오 편입 여부와 무관 — 이것이 CAGR 추정량과의 결정적 차이다).

### 3-2. 종속변수 — 전방수익률

**엔진과 비트 단위로 같은 정의를 쓴다.** 새로 정의하지 않는다.

```python
# backtest/engine.py 와 scripts/export_portfolios.py 의 규약을 그대로 재사용
entry = get_close_price(conn, ticker, rebal_date)
if is_delisted_at(conn, ticker, next_date):
    exit_ = _last_known_price(conn, ticker, next_date) * DELISTING_HAIRCUT
else:
    exit_ = get_close_price(conn, ticker, next_date)
fwd_ret = exit_ / entry - 1
```

> **사전등록 D-1 — 상폐 종목은 패널에서 제외하지 않는다.**
> 제외하면 생존편향이 IC에 직접 들어온다. 저PBR 종목의 상폐율이 높다면
> 제외된 패널의 IC는 **위쪽으로 편향**된다. 상폐 haircut 수익률을 그대로 쓴다.
> `[Claude 의견]` 이것은 CAGR 추정량에서는 이미 지켜지고 있던 것이지만
> (holdings tape에 `delisted` 플래그 존재), 횡단면 패널을 새로 만들 때
> 조용히 `dropna()` 로 사라지기 가장 쉬운 항목이다. §5 L-1 배관 게이트가 이를 잡는다.

`[VERIFY]` `DELISTING_HAIRCUT` 상수값과 `price_history` 결측 시 동작을 실행 전에 실측 확인.

### 3-3. 독립변수 — 신호

```
inv_pbr_total = 자본총계 / 시가총액        # 총액 기준 (BASIS-RIM-001, 2026-07-17)
```

**주당 지표를 쓰지 않는다.** `price_history` 수정주가는 현재 기준 리베이스이고
`market_cap_history` PIT 주식수는 당시 기준이라, 분할·무상증자 종목에서 배수로 틀어진다
(SPEC_03 / `pipeline.score_and_rank` 주석). 총액 비교는 그 문제가 식에서 사라진다.

**결측·이상 처리 (사전등록)**:

| 경우 | 처리 | 근거 |
|---|---|---|
| 자본총계 결측 | 패널 제외 + **구간별 제외율 보고** | 랭킹 자체가 불가 |
| **자본총계 ≤ 0** | `[VERIFY]` **엔진의 실제 동작을 먼저 실측하고 그대로 따른다** | 엔진이 이들을 어떻게 처리하는지 확인 전에는 규칙을 쓸 수 없다. 음수 BM은 랭킹 최상위로 튄다 |
| 판정불가 구간 (2016-08-18, R5·R6 = 0%) | **제외**. 단 제외 전후 결과 병기 | CLOSEOUT §4 — 유일한 오염 구간 |

### 3-4. 표준화 — 구간별 횡단면

```
1) 구간 t 내에서 inv_pbr 을 rank → [0,1] uniform → 역정규변환 (z)
2) 종속변수 fwd_ret 은 primary(rank IC)에서는 rank, FM 회귀에서는 1/99 pct winsorize
```

`[Claude 의견]` 한국 소형주 반기 수익률은 극단 꼬리가 두껍다. 원자료 Pearson 상관은
**단일 종목 1건**에 좌우될 수 있다. rank 변환이 primary인 이유다. winsorize 대신
trimming을 쓰지 않는 이유는 trimming이 관측을 버려 IC를 낙관 쪽으로 밀 수 있어서다.

### 3-5. 통제변수 (FM 회귀 전용)

| 변수 | 정의 | 비고 |
|---|---|---|
| `log_mktcap` | log(시가총액), 구간별 z | 소형주 효과 분리 |
| `mom_126` | SPEC_12 §3-0(a) formation 126 / skip 21 | 신호가 모멘텀의 재포장인지 확인 |
| `log_turnover` | 일평균 거래대금 log, 구간별 z | 유동성 프리미엄 분리 |

> 통제 없는 단순 회귀도 함께 보고하되 **primary는 3개 통제 포함**이다.

## 4. 추정량

### 4-1. Rank IC — **primary**

```
IC_t = Spearman( inv_pbr_i,t ,  fwd_ret_i,t )        i ∈ L3(t)
보고: mean(IC), sd(IC), ICIR = mean/sd, t = ICIR × sqrt(T),  구간별 IC 시계열 플롯
```

### 4-2. Fama-MacBeth — 병기 primary

```
단계 1 (구간별 횡단면 OLS):
    fwd_ret_i,t = a_t + λ_t · z(inv_pbr)_i,t + γ_t · controls_i,t + e_i,t
단계 2 (시계열):
    λ̄ = mean(λ_t),   t = λ̄ / (sd(λ_t)/sqrt(T)),   df = T−1
```

`[검증된 사실]` FM은 구간 내 잔차 상관(시장·업종 공통 충격)을 **구성상** 흡수한다.
그것이 패널 OLS 대신 FM을 쓰는 이유다 — 패널 OLS는 SE를 심하게 과소추정한다.

### 4-3. 추론 — T=18에서의 SE

| 방법 | 지위 | 사유 |
|---|---|---|
| **permutation 귀무분포** (구간 내 신호 재배열, B=1,000) | **primary** | 프로젝트 관례(SPEC_10 §3-1, SPEC_12 §6-3)와 일치. T=18에서 정규 근사보다 정직하다 |
| FM 표준 t (df=17) | 병기 | 관례적 보고 |
| Newey-West | **비중첩 반기에서는 미적용** | 6개월 forward / 6개월 rebal = 중첩 0. 중첩 없는데 NW를 쓰면 lag 선택이 임의값이 된다. §4-4 월간 확장에서만 적용 |

> **단측 검정을 쓴다.** 가치 프리미엄은 방향 가설이 있다(1/PBR 高 → 수익 高).
> **사전등록 P-1a**: 단측, α=0.05. 결과가 반대 부호로 유의하면 그것은 PASS가 아니라
> **"신호가 반대 방향"** 이라는 별도 결론이며, 부호를 뒤집어 재검정하지 않는다.

### 4-4. 월간 재표본 확장 — 2차, 판정 보조

```
횡단면 시점: 매월 말 (T ≈ 120)
신호:        그 시점의 최신 PIT 재무 / 그 시점 시가총액   ← 분모는 매월 갱신
종속:        1개월 전방수익률  (중첩 0)  ← 6개월 중첩본은 NW(lag 5) 병기
```

`[Claude 의견]` 이것이 T를 실제로 늘리는 유일한 경로다. 다만 **신호 자기상관이 크다**
(분자가 반기 갱신). 유효 독립 관측 수는 120이 아니라 그보다 훨씬 작다.
따라서 **월간 결과가 반기 결과와 어긋나면 반기 primary를 따른다** —
반기 캘린더가 실제 전략의 캘린더이기 때문이다.

> **사전등록 P-1b**: 월간 확장은 **primary가 아니다.** 반기 primary가 FAIL인데
> 월간이 PASS인 경우를 "PASS"로 보고하지 않는다.

### 4-5. 가중 — 동일가중 primary

실제 포트폴리오가 동일가중이므로 횡단면 회귀도 동일가중이 정합이다.
√시총 가중은 **강건성 축으로만** 병기(초소형주 잡음 지배 여부 확인).

| **P-2** | **양성 대조 (약) — 검출기 감도** | `fwd_ret` + 노이즈로 **설계 IC ≈ 0.03 / 0.05** 합성 신호 생성 | 각 수준에서 검출 성공률 보고. **이것이 §6 검출력의 실측 근거다** |

> `[Claude 의견]` **N-2가 이 SPEC 고유의 안전장치다.** 데이터 무결성 점검이 여덟 세션에 걸쳐
> lookahead 없음을 확인했지만(CLOSEOUT §1), 그것은 **기존 조회 경로**에 대한 확인이다.
> SPEC_15는 **새 조회 경로**를 만든다. 새 배관에는 새 양성 대조가 필요하다.

> **워크트리 대조 방법론을 쓴다.** monkeypatch는 이 저장소에서 두 번 실패했다
> (CLOSEOUT §7). 하네스 충실성은 음성 대조(무패치 == 패치+원본소스)로 먼저 확인한다.

## 6. `[선행 산출 A-2]` 검출력 — 결과 열람 전 확정

**IC 평균을 보지 않고 산출한다.** 재료는 N-1 permutation 분포의 sd 와 P-2 실측이다.

```
MDE(IC) = t_crit(df=T−1, 단측 0.05) × sd_null(IC) / sqrt(T)  ... 정규근사
          + P-2 에서 설계 IC 0.03 / 0.05 의 실제 검출 성공률로 교차 확인
```

> **사전등록 A-2 기록 의무**: 산출된 MDE(IC)를 **결과 산출 전에 커밋한다.**
> FAIL이 났을 때 "효과가 없다"와 "검출력이 없다"를 구분할 유일한 수단이다.
> MDE가 문헌 전형값(장기 가치 신호 IC 0.02~0.05)보다 크면, **그 사실 자체가
> 이 SPEC의 결론**이 될 수 있다 — 즉 "이 표본으로는 어떤 추정량으로도 판정 불가".

## 9. 한계 — 실행 전 명시

### 9-1. T는 여전히 18~20이다
FM t의 자유도는 늘지 않는다(§1-3). 이 SPEC은 **잡음을 줄이는 것**이지
**표본을 늘리는 것이 아니다.**

### 9-2. 섹터 통제 불가
`SECTOR-DATA` 미해결. 저PBR이 특정 업종에 몰려 있으면 IC는 **업종 베팅의 산물**일 수
있고 이 설계는 그것을 분리하지 못한다. `[Claude 의견]` G5 낙폭 원인 규명에서도 같은
병목이었다 — SPEC_15의 결론에 이 한계를 반드시 병기한다.

### 9-3. IC → IR 전환: breadth 산술 **(실행 전에 읽을 것)**

Grinold의 근사 `IR ≈ IC × sqrt(breadth)`:

```
breadth = 종목 수 × 연간 리밸런싱 횟수
n=13, 반기 2회  →  breadth = 26  →  sqrt = 5.1
n=20, 반기 2회  →  breadth = 40  →  sqrt = 6.3

IC = 0.03  →  IR ≈ 0.15 (n=13) / 0.19 (n=20)
IC = 0.05  →  IR ≈ 0.25 (n=13) / 0.32 (n=20)
```

`[Claude 의견]` **문헌 전형 수준의 IC가 사실이어도 이 구조의 실현 IR은 0.2~0.3이다.**
그리고 IR 0.2를 T=18 표본에서 CAGR로 검출하는 것은 §1-2 MDE에 비추어 불가능하다.
**즉 "IC PASS + G1 FAIL"은 예상 가능한 정합적 결과다.** 이것을 미리 적어두지 않으면
결과를 보고 사후에 지어낸 변명처럼 읽힌다.

이 산술은 또한 **breadth가 진짜 병목일 수 있음**을 시사한다 — 다만 그것은 SPEC_15의
결론이 아니라 후속 SPEC의 가설이며, **여기서 종목 수를 바꾸지 않는다.**

### 9-4. 유동성
IC가 거래 불가능한 초소형주에서 나올 수 있다. **거래대금 3분위별 IC를 진단으로 보고**한다
(판정 비사용).

## 부록 — 용어

**IC (Information Coefficient)**: 한 시점에서 신호 순위와 이후 실현수익 순위의 상관.
포트폴리오를 만들지 않고 신호 자체의 예측력을 재는 지표.

**ICIR**: IC 평균 ÷ IC 표준편차. 신호가 얼마나 **꾸준히** 맞는지.

**Fama-MacBeth**: 시점별 횡단면 회귀 계수를 먼저 구하고(1단계), 그 계수 시계열의 평균을
검정하는(2단계) 2단 추정. 구간 내 잔차 상관을 구성상 흡수한다.

**Breadth**: 독립적 베팅의 수. `IR ≈ IC × √breadth` (Grinold). 신호가 좋아도 베팅 수가
적으면 실현 성과는 잡음에 묻힌다.

**MDE (Minimum Detectable Effect)**: 주어진 표본·검정력에서 검출 가능한 최소 효과 크기.
**FAIL의 의미를 해석하려면 필수다** — MDE를 모르면 "효과 없음"과 "검출력 없음"이 구분되지 않는다.

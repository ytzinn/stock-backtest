## §2. `gate_analysis` fail-closed 가드 — **가장 먼저 세웠다**

`[검증된 사실]` 이 스크립트는 전 구간에서 G1 을 **스스로 다시 계산**한다. 현행 G1(FAIL)은
`e2c2b8d` 가 n=18 절단 집합에서 낸 것이라, 인자 없이 돌리면 사전등록 판정이 조용히 덮인다.

`--period-set` 을 **`required=True`** 로 넣었다. **기본값을 두지 않은 이유는 기본값이 곧
사고 경로이기 때문이다.**

| 호출 | rc | 메시지 |
|---|---:|---|
| `--period-set` 없이 | **2** | `error: the following arguments are required: --period-set` |
| `--period-set NOPE` | **1** | `알 수 없는 period_set: 'NOPE'` |

### 2-1. sha 규약 — 직전 세션들과 동일함을 확인

```
SPEC15_T19_primary   7b1d7489522f8747   n=19
SPEC15_T18_g1compat  d318d475e89c438d   n=18   ← G1·G5·G2 판정 집합
full                 (절단 없음)
```

`[검증된 사실]` A-0 산출물이 박아 둔 값과 **정확히 일치**한다. 자동 대조가 성립한다.

### 2-2. `[리팩터]` 순수 함수를 DB 없는 모듈로

`compose_gate_results` 에 `assert_no_db_imported` 를 걸었더니 **발화했다** —
`gate_analysis` 를 import 하면 `run_ablation → backtest.engine → psycopg2` 가 딸려온다.
접속은 하지 않지만 가드는 그보다 엄격하다.

`period_set_sha` · `resolve_period_set` 을 `scripts/analysis/period_set_lib.py` 로 옮겼다.
**규약이 한 곳에만 있게 되는 부수 효과**를 얻었다 — 산출물마다 규약이 갈리면 자동 대조가
깨지는데, 그것을 구조로 막는다.

### 2-3. 오라클 (11건, 메타 4건 포함)

음성 대조: 규약에서 `sorted()` 를 제거해 주입 → `test_sha_convention_is_sorted_lf_joined`
발화. `[Claude 의견]` 다른 테스트가 안 걸린 이유는 **산출물의 `dates` 가 이미 정렬돼 있어서**다

## §3. `run_ablation` scratch 재현 — **비트 동일 아님**

### 3-1. `[편차]` `--output-dir` 이 아니라 **cwd 이동**을 썼다

`[검증된 사실]` **`run_ablation` 에 `--output-dir` 플래그는 존재하지 않는다.**
`OUT_DIR` 은 모듈 상수다.

더 중요한 것은, 플래그를 새로 만들었더라도 **전부를 보내지 못했을 것**이라는 점이다 —
`backtest/filters/momentum_criteria.py:29` 에 `DIAG_DIR = Path('experiments/momentum_criteria')`
라는 **두 번째 쓰기 위치**가 있고 `run_ablation` 경로에서 도달한다.
지시서가 경고한 "일부 경로만 리다이렉트되는 구현" 이 정확히 그 상황이다.

**그래서 cwd 자체를 옮겼다.** 모든 쓰기가 cwd 상대경로라 **구성상 총체적**이고,
판정 산출물 생성 코드를 한 줄도 고치지 않는다.

`[검증된 사실]` 사후 총체성 확인 — scratch 에 생긴 파일 전부:
```
experiments/ablation/F_pbr_ma200_n13.json
experiments/ablation/F_pbr_ma200_n13_periods.csv
experiments/ablation/F_pbr_ma200_n13_coverage.csv
experiments/ablation/summary.json
experiments/momentum_criteria/F_pbr_ma200_diagnostics_summary.json   ← DIAG_DIR 도 잡혔다
```
그리고 워크트리 등재본 3종은 sha 무변경.

### 3-2. diff 범위 — **판정 컬럼은 전 행 동일**

23행 중 **5행**이 다르다: `2024-04-03`, `2024-08-20`, `2025-04-03`, `2025-08-20`, `2026-04-03`.

| 컬럼 | 다른 행 수 | 어느 구간 |
|---|---:|---|
| `period_return` | **0** | — |
| `net_return` | **0** | — |
| `turnover` | **0** | — |
| `transaction_cost` | **0** | — |
| `n_gate` · `n_stocks` · `screener_passed` | **0** | — |
| `next_date` | 1 | `2026-04-03` (열린 구간) |
| `kospi_return` · `kosdaq_return` | 1 | `2026-04-03` (같은 구간) |
| **`hard_passed`** | **5** | 2024-04-03 이후 전부, **모두 감소** |
| `stability_passed` | 2 | `2024-04-03`, `2024-08-20` |
| `momentum_passed` | 1 | `2024-04-03` |

`[검증된 사실]` **판정에 쓰이는 네 컬럼은 23행 전부 비트 동일하다.**
차이는 (a) 열린 구간의 `date.today()` 의존(`2026-08-14` → `2026-08-29`, 벤치마크 창이
길어져 지수 수익률도 따라 움직임)과 (b) **필터 통과 개수**뿐이다.

`hard_passed` 예: `2024-04-03` 1887 → 1856 · `2025-08-20` 2016 → 1983.

### 3-3. `[중단]` 승격하지 않는다

지시서 §2-1 의 판정표대로 **다름 → 중단, 승격 금지**다. 그리고 §4 는 §2 해소를 전제로
하므로 **`make_canonical` 도 실행하지 않았다.**

`[Claude 의견]` 판정 컬럼이 전부 같으니 승격해도 되지 않느냐는 유혹이 있다.
**그러면 안 된다.** 승격의 목적은 "`periods.csv` 와 같은 상태에서 나온 요약 JSON" 을
등재 위치에 두는 것인데, 지금 확인된 것은 **그 전제가 성립하지 않는다**는 사실이다.
판정 컬럼이 같다는 것은 *다행*이지 *허가*가 아니다.

## §4. 게이트 표 조립 경로 — **만들었으나 쓰지 않았다**

`scripts/robustness/compose_gate_results.py`. **게이트 값을 계산하지 않는다** —
등재 산출물 둘을 읽어 생성기가 기대하는 모양으로 옮기기만 한다.

`[Claude 의견]` `gate_analysis` 를 돌려 채우는 길도 있었지만 그것은 전 구간에서 G1 을
다시 계산한다. **값을 만드는 경로와 옮기는 경로를 분리해 두면, 이 세션이 조용히 판정
세션이 되는 일이 구조적으로 막힌다.**

fail-closed 검사 넷, `--dry-run` 에서 전부 통과:

| 검사 | 결과 |
|---|---|
| G5G2 산출물의 sha256 ↔ 자기 `dates` | 자기정합 |
| **구간 집합 sha 역참조** | `d318d475…` → `SPEC15_T18_g1compat` (이름을 손으로 붙이지 않는다) |
| 구간 수·경계 일치 (G1 ↔ G5G2) | n=18, `2017-04-05`~`2026-04-03` |
| **두 산출물의 F net CAGR 일치** | `0.140077499394` — 서로 다른 세션의 독립 경로 |

조립값 (`--dry-run`, **파일로 쓰지 않았다**):
```
G1 FAIL  CAGR 15.6299% vs 귀무 p95 17.9716%
G2 PASS  net  14.0077% vs U       7.2406%
G5 FAIL  일별 net MDD -57.8177% vs 한계 -45.00%
```

`make_canonical` 도 손봤다(아직 재실행하지 않음) — 헤더에 `period_set`(id·n·sha)을 찍고,
`caveat` 필드가 있으면 **판정 옆에** 붙인다. G2 단서(벤치마크 모멘텀이 MA 20/60,
채택안은 MA200)가 표에서 떨어지지 않게 하려는 것이다.
